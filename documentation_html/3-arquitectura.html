3.1. Diseño General:

La aplicación sigue una arquitectura de aplicación web progresiva (PWA) con enfoque en el frontend. La arquitectura se basa en componentes JavaScript modulares que interactúan con APIs externas y APIs nativas del navegador.

3.2. Capas y Módulos:

  • Capa de Presentación: Templates HTML y estilos CSS
  • Capa de Lógica de Aplicación: Módulos JavaScript (app.js, api.js, forecast.js, location.js, menu.js)
  • Capa de Servicios: Service Worker para funcionalidades offline
  • Capa de Datos: AccuWeather API como fuente externa de datos

3.3. Patrones de Diseño:

  • Módulo: Organización del código en módulos JavaScript separados
  • Service Worker: Para caching y funcionalidades offline
  • API Client: Módulo dedicado para comunicación con APIs externas

3.4. Flujo de Datos Principal:

  1. El usuario accede a la aplicación
  2. La aplicación solicita permisos de geolocalización
  3. Se obtiene la ubicación del usuario mediante Geolocation API
  4. Se consulta la API de AccuWeather con la ubicación obtenida
  5. Se procesan y muestran los datos meteorológicos
  6. El Service Worker cachea recursos para funcionamiento offline

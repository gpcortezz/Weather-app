7.1. Visión General de la API:

La aplicación Weather-app es una Progressive Web App (PWA) que consume la API externa de AccuWeather para proporcionar información meteorológica. La aplicación utiliza JavaScript del lado del cliente para realizar llamadas a la API de AccuWeather y no implementa un backend propio con endpoints REST tradicionales.

Características principales de la API:

  • Consumo exclusivo de la API externa de AccuWeather
  • Implementación frontend con JavaScript ES6+
  • Uso de Fetch API para las solicitudes HTTP
  • Integración con Geolocation API del navegador
  • Arquitectura basada en Service Workers para funcionalidad PWA
  • No requiere autenticación propia (la autenticación se maneja mediante API key de AccuWeather)

7.2. Lista Completa de Endpoints:

Endpoint Método HTTP Descripción Base URL Autenticación
AccuWeather Location Search GET Busca ubicaciones basadas en coordenadas geográficas o nombre de ciudad http://dataservice.accuweather.com/locations/v1 API Key (AccuWeather)
AccuWeather Forecast GET Obtiene el pronóstico meteorológico para una ubicación específica http://dataservice.accuweather.com/forecasts/v1 API Key (AccuWeather)

7.3. Detalle de Endpoints Clave:

Endpoint: AccuWeather Location Search

Descripción: Este endpoint permite buscar ubicaciones utilizando coordenadas geográficas (latitud/longitud) o nombre de ciudad para obtener el location key necesario para consultar el pronóstico.

Parámetros de Entrada:

Parámetro Tipo Descripción Obligatorio
apikey string API Key de AccuWeather para autenticación Sí
q string Consulta de búsqueda (nombre de ciudad o coordenadas) Sí
language string Idioma de la respuesta (ej: es-ES, en-US) No

Ejemplo de Request:

// Búsqueda por coordenadas
GET http://dataservice.accuweather.com/locations/v1/cities/geoposition/search?apikey=TU_API_KEY&q=40.7128,-74.0060

// Búsqueda por nombre de ciudad
GET http://dataservice.accuweather.com/locations/v1/cities/search?apikey=TU_API_KEY&q=New York

Endpoint: AccuWeather Forecast

Descripción: Este endpoint proporciona el pronóstico meteorológico detallado para una ubicación específica utilizando el location key obtenido del endpoint de búsqueda.

Parámetros de Entrada:

Parámetro Tipo Descripción Obligatorio
apikey string API Key de AccuWeather para autenticación Sí
locationKey string Clave de ubicación obtenida del endpoint de búsqueda Sí
language string Idioma de la respuesta (ej: es-ES, en-US) No
details boolean Incluir detalles adicionales del pronóstico No
metric boolean Usar unidades métricas (true) o imperiales (false) No

Ejemplo de Request:

// Pronóstico de 1 día
GET http://dataservice.accuweather.com/forecasts/v1/daily/1day/349727?apikey=TU_API_KEY&metric=true

// Pronóstico de 5 días
GET http://dataservice.accuweather.com/forecasts/v1/daily/5day/349727?apikey=TU_API_KEY&metric=true

  • Las unidades métricas/imperiales se controlan con el parámetro "metric"
  • El location key debe ser válido y corresponder a una ubicación soportada por AccuWeather
  • Las respuestas incluyen información detallada sobre temperatura, condiciones climáticas y precipitaciones

Implementación en la Aplicación:

La aplicación Weather-app implementa estos endpoints a través de los siguientes módulos JavaScript:

  • scripts/api.js: Maneja las llamadas HTTP a la API de AccuWeather
  • scripts/location.js: Gestiona la obtención de la ubicación del usuario
  • scripts/forecast.js: Procesa y muestra los datos del pronóstico

Ejemplo de implementación en código:

// En scripts/api.js
async function getWeatherData(locationKey) {
    const apiKey = config.accuWeatherApiKey;
    const url = `http://dataservice.accuweather.com/forecasts/v1/daily/5day/${locationKey}?apikey=${apiKey}&metric=true`;
    
    try {
        const response = await fetch(url);
        if (!response.ok) {
            throw new Error(`HTTP error! status: ${response.status}`);
        }
        return await response.json();
    } catch (error) {
        console.error('Error fetching weather data:', error);
        throw error;
    }
}

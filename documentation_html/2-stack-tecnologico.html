2.1. Tecnologías Principales:

  • Frontend: HTML5, CSS3, JavaScript ES6+
  • APIs Nativas del Navegador: Geolocation API, Fetch API, Service Workers
  • Arquitectura: Progressive Web App (PWA)
  • APIs Externas: AccuWeather API (location y forecast endpoints)

2.2. Dependencias Externas Clave:

  • AccuWeather API: Para obtención de datos meteorológicos y ubicación
  • Live Server (desarrollo): Servidor de desarrollo local en puerto 5501

2.3. Herramientas de Desarrollo Sugeridas:

  • Visual Studio Code (con extensión Live Server)
  • Navegadores web modernos con soporte para Service Workers
  • Herramientas de desarrollo del navegador para debugging PWA

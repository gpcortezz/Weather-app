5.1. Requisitos del Sistema:

  • Navegador web moderno con soporte para JavaScript ES6+
  • Servidor web para hosting (puede ser servidor estático)
  • Conexión a internet para consumo de APIs externas
  • Acceso a la API de AccuWeather (claves de API requeridas)

5.3. Pasos de Instalación (Entorno de Desarrollo):

  1. Clonar el repositorio: git clone https://github.com/gpcortezz/Weather-app.git
  2. Abrir el proyecto en Visual Studio Code
  3. Instalar la extensión Live Server
  4. Configurar las claves de API de AccuWeather en config.js
  5. Ejecutar con Live Server (puerto 5501 por defecto)

5.4. Pasos de Despliegue (Entorno de Producción):

  1. Configurar un servidor web estático (Apache, Nginx, o servicio de hosting)
  2. Subir los archivos del proyecto al servidor
  3. Configurar HTTPS (requerido para Service Workers)
  4. Verificar que el Service Worker esté registrado correctamente
  5. Probar la funcionalidad de geolocalización y APIs
